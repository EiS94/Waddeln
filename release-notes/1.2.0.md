# Waddeln 1.2.0

## Neu

### Mitspieler einladen (#5)
- In der Lobby kannst du den Raum-Code kopieren (Knopf „Kopieren“ oder auf den Code tippen).
- „Einladen“ öffnet das Teilen-Menü (WhatsApp, Signal, SMS …) mit einem Link zum Raum.
- Wer die App hat und auf den Link tippt, landet direkt im Raum. Ohne Spitznamen steht der Code schon
  bei „Raum beitreten“ bereit. Sitzt du gerade in einem anderen Raum, fragt die App, ob du wechseln willst.
- Ohne App zeigt der Link eine kleine Seite mit dem Raum-Code.

### Spielregeln in der App (#6)
- Neuer Menüpunkt „Spielregeln“: alle Regeln für Einsteiger erklärt, in Abschnitten zum Aufklappen
  und mit Kartenbildern als Beispiele.

### Wer kommt raus? (#7)
- Bis die erste Karte liegt, zeigt der Tisch, wer rauskommt – auch während ein Schub offen ist.
  Kommst du selbst raus, steht es über deinen Karten.
